\# 🛒 ShopEase – Modern E-Commerce Frontend Website

ShopEase is a fully responsive frontend e-commerce website built using **HTML, CSS, and Vanilla JavaScript**.  
The project demonstrates modern UI/UX design principles, dynamic product rendering, cart management, filtering, sorting, and form validation without using any frontend frameworks.

---

## 🚀 Live Features

- ✅ Responsive modern UI
- ✅ Dynamic product catalog
- ✅ Product search & category filtering
- ✅ Product sorting
- ✅ Product detail pages
- ✅ Shopping cart functionality
- ✅ Quantity management
- ✅ Dynamic order summary calculation
- ✅ Login & signup form validation
- ✅ Toast notifications
- ✅ Mobile-friendly navigation
- ✅ Reusable JavaScript utility functions
